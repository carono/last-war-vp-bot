# 1. Установка Python 3.12

Бот написан на Python 3.12. Версия 3.13 пока избегается — часть CV/ML-библиотек ещё не имеет под неё готовых wheel-пакетов.

## Установка

1. Открой [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. Скачай **Windows installer (64-bit)** для последней 3.12.x.
3. Запусти установщик. **Обязательно поставь галочку «Add python.exe to PATH»** на первом экране.
4. Выбери `Install Now`.
5. После установки на финальном экране нажми **«Disable path length limit»** (снимает ограничение в 260 символов — иногда мешает pip).

## Проверка

Открой **новое** окно PowerShell (старое не увидит обновлённый PATH):

```powershell
python --version
```

Ожидаемый вывод — что-то вроде `Python 3.12.7`. Если выводит `3.13.x` или ничего — переустанови с галочкой PATH и убедись, что в `Программы и компоненты` нет лишних версий впереди в PATH.

Также проверь `pip`:

```powershell
python -m pip --version
```

Должно отдать `pip 24.x ... (python 3.12)`.
